# Weekly review

Help the owner close the week and plan the next one.

1. Read the activity log (`activity_log`, about 100 entries) and list what you did on your own this week.
2. List routines and flag any that failed (`lastStatus: error`) or look stale.
3. Recall open projects and commitments from memory.
4. Send a short summary: done this week, still open, and next week's dated items.
5. Ask one question: what the owner wants to focus on next week. Save the answer to memory.
6. Offer to prune the heartbeat checklist if items look finished.
